# OpsPilot

OpsPilot is a production-oriented AI operations platform built as a portfolio and learning project.

## Current Status

Stage 0 — Engineering Design

## Goals

The project will explore:

- backend engineering
- relational databases
- RAG
- LLM tool calling
- agentic workflows
- AI evaluation
- AI security
- human-in-the-loop workflows
- cloud deployment
- observability
