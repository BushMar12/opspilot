# Northstar Commerce — Delivery Issue Policy

## 1. Purpose

This policy defines the investigation process for delivery-related customer complaints.

## 2. Delayed deliveries

Support agents must verify the order status and available tracking information before providing a delivery estimate.

Agents must not provide unverified delivery guarantees.

## 3. Missing deliveries

When a customer reports an order as missing, the support agent must confirm the order identifier and investigate the available delivery records.

If the delivery status cannot be verified, the issue must be escalated for manual investigation.

## 4. Damaged deliveries

Customers reporting damaged products should be asked to provide sufficient details about the condition of the delivered items.

Support agents must create or update a support ticket containing the reported issue and related order information.

## 5. Refunds and replacements

Refunds and replacements resulting from delivery issues must comply with the Refund and Return Policy.

## 6. Customer communication

Support agents must provide accurate information based on verified records and clearly communicate any unresolved uncertainty.
